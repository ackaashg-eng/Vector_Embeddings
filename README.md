# Text-to-Vector Explorer

## Description
A beginner-friendly Python project that represents words as numerical vectors and explores the relationships between them.

## Features
- Stores 25 words across five categories: Technology, Food, Animals, Sports, and Vehicles.
- Displays words, vectors, and vector dimensions.
- Compares two vectors and calculates Euclidean distance.
- Identifies the closest pair of vectors.
- Visualizes vectors in 2D using Matplotlib.

## Technologies Used
- Python
- Matplotlib

## Installation

Install Matplotlib:

```bash
python -m pip install matplotlib
```

## How to Run

```bash
python text_to_vector_explorer.py
```

## Learning Objectives
- Understand numerical vector representations.
- Learn vector dimensions and Euclidean distance.
- Compare vectors and identify the closest pair.
- Visualize numerical coordinates using Matplotlib.

## Note
The vectors are manually assigned for learning purposes and do not represent actual word meanings.
